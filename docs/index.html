ByteDo Firmware XUSB ID Patcher

Reads an 8BitDo Ultimate 2C controller firmware update (.dat) file, lets you patch the 4-byte XUSB ID so you can use more than one of these on your hacked Xbox 360.

The source code can be found on GitHub.
